# signal-ios-build-verification

Checks whether the App Store build of **Signal iOS 8.35.1 (build 1964)** matches its public source code.

**Result:** the compiled code (`__TEXT,__text`) of all five first-party binaries (`Signal`, `SignalServiceKit`, `SignalUI`, `SignalNSE`, `SignalShareExtension`) is **byte-identical** to a local build of tag [`8.35.1.1964`](https://github.com/signalapp/Signal-iOS/tree/8.35.1.1964) made with Xcode 27.1 (27A9275). Every remaining byte difference is accounted for and harmless: signature size, a UUID, and a linker GOT-slot ordering that also varies between two identical local builds. The bundled third-party frameworks match the pinned versions. Two planted-backdoor builds were both detected, including a one-line key-weakening change.

This shows the shipped app is built from the public source. It does **not** show that the public source itself is free of backdoors. See the limitations in the report.

- Report: [`report/report.pdf`](report/report.pdf) (source: `report/report.typ`, built with Typst)
- Harness: `verify/` (Python standard library + Apple command-line tools)
- Results: `verify/out/` (diffs and summaries; the full per-function dumps are regenerated by the scripts)
- Planted-backdoor controls: `verify/controls/*.patch`

The 8.35.1 report and its files stay at their original paths. Later versions go under `versions/<version>/`, each with its own decrypted app, outputs and report, and all use the shared harness in `verify/`.

## Reproducing

You need a Mac with Xcode 27.1 (27A9275). The decrypted app is included at `signal_dec/Payload/Signal.app`; to check it independently, decrypt your own copy of Signal 8.35.1 (1964) and compare hashes. The decryption here was done with [unfairplay](https://github.com/DrWhax/unfairplay). Section 10 of the report has the full build commands. In short:

```sh
# build tag 8.35.1.1964 at /Volumes/workspace/repository (see report §10), then:
verify/compare_build.sh signal_dec/Payload/Signal.app \
  /Volumes/workspace/build-A.xcarchive/Products/Applications/Signal.app verify/out/ipa_vs_A
python3 -I verify/summarise.py verify/out/ipa_vs_A
```

## Contents

- `signal_dec/`: the decrypted App Store app (Signal 8.35.1, build 1964) used for the analysis, so the comparison can be re-run without decrypting your own copy. `iTunesMetadata.plist` and `META-INF/` are left out because they are tied to the download. Each binary's SHA-256 is in `verify/out/provenance_ipa.txt`; you can check them against your own decrypted copy.
- `original_prompt.txt`: the request that started this work, verbatim.
- `report/`, `verify/`: the report and the harness described above.

The full per-function disassembly dumps (about 4 GB) are not included; `verify/compare_build.sh` regenerates them.
